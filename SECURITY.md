# Security policy

This repository contains intentionally vulnerable, isolated contracts for
education and local testing. They are not production protocols, and the demo
tokens have unrestricted minting.

If you find an unintended issue in the lab code or its CI configuration, please
open a private GitHub Security Advisory when the repository supports advisories.
If private advisories are unavailable, contact the repository maintainer
privately before publishing details. Do not send secrets, private keys, or live
RPC credentials in an issue.

Historical exploit tests run against a local fork and do not broadcast
transactions.
